Build a shared, multi-user team project workspace as a deployable full-stack web app.

CRITICAL REQUIREMENT — SHARED DATA:
All data must be stored centrally in a server-side database (use a persistent DB — Postgres or SQLite is fine). Every visitor to the app URL sees the same, up-to-date content. When one person edits something, others see it after a refresh. Implement a lightweight REST API and have the frontend poll the server every ~5 seconds so changes from teammates appear automatically. Do NOT use browser localStorage for shared state — that was the problem with our previous version, where each person only saw their own edits.

No login required: anyone with the URL can view and edit. For attribution on brainstorm ideas, just ask the user to type their name in a field (no accounts).

Historically, deviations trace back to one of two sources: the source data, or the manual mapping files we maintain.
