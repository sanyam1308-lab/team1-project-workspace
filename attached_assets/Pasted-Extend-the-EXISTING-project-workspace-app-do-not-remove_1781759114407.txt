=== TABLEAU CONNECTION MODULE ===
1. Sign in: POST https://{TABLEAU_POD}.online.tableau.com/api/{TABLEAU_API_VERSION}/auth/signin
   Body: credentials with personalAccessTokenName, personalAccessTokenSecret, and the site contentUrl.
   The response returns an auth token (valid ~120 minutes) and a site id. Cache the token and re-sign-in when it expires.
2. List available fields (for setup/debug): POST https://{TABLEAU_POD}.online.tableau.com/api/v1/vizql-data-service/read-metadata
   Header: X-Tableau-Auth: <token>. Body includes the datasourceLuid.
3. Query data: POST https://{TABLEAU_POD}.online.tableau.com/api/v1/vizql-data-service/query-datasource
   Header: X-Tableau-Auth: <token>. Body includes the datasourceLuid and the list of fields to fetch. The response is JSON rows.
Add a "Test connection" function that signs in and returns the field list, so I can confirm it works.

=== WHICH METRICS TO MONITOR ===
Add a small config (stored in the database, editable from the UI) where I list the fields/metrics to monitor — e.g. a measure like "Revenue" optionally broken down by a dimension like "Region". Default to a single total measure if I haven't configured anything yet.

=== AGENT RUN LOGIC (one "run") ===
1. Pull the current values of the monitored metrics from Tableau via the query module.
2. Compare each metric to the most recent saved snapshot in the database (the previous run). Flag a DEVIATION when: the absolute percentage change exceeds a configurable threshold (default 10%), OR a value becomes null/zero/missing.
3. Save the new pull as the latest snapshot (keep a history of snapshots).
4. For each deviation, call the Claude API to reason about the likely root cause. Send it: the metric name, previous vs current value and % change, and this context — "Deviations in these revenue dashboards historically come from one of two sources: (a) the raw source data, or (b) the manual mapping files the team maintains. You give a DIRECTIONAL indicator, not a final verdict; a human confirms and fixes."
   Ask Claude to respond ONLY as JSON:
   { "likely_cause": "source_data" | "mapping_files" | "unclear",
     "confidence": "high" | "medium" | "low",
     "explanation": "one or two plain-language sentences",
     "recommended_check": "the single first thing the owner should check" }
   Use model "claude-sonnet-4-6". Parse the JSON safely (strip code fences); on parse failure, store the raw text and mark confidence "low".
5. Save each deviation + Claude's directional indicator to the database with a timestamp.
